# 📚 Digital Library Management System

A web-based Library Management System developed to simplify library operations, including book management, student management, book issuing, and returning.

## 📌 Project Overview

The Digital Library Management System is designed to help administrators manage library resources efficiently and enable students to access book information easily. The application provides a simple and user-friendly interface for organizing library activities.

## ✨ Features

- **User Authentication:** Login and registration functionality.
- **Admin Dashboard:** View library statistics and manage library activities.
- **Book Management:** Add, edit, delete, search, and view books.
- **Student Management:** Manage student information.
- **Issue Books:** Record books issued to students.
- **Return Books:** Update book issue records when books are returned.
- **Search Books:** Find books using available search options.
- **My Books:** Allow students to view their issued books.
- **Book Cover Images:** Display book cover images for easier identification.
- **Dashboard Statistics:** View book, student, and issued-book counts.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Database Management Tool:** phpMyAdmin
- **Charts:** Chart.js (for dashboard visualization, if included)

## ⚙️ Installation and Setup

### Prerequisites

- XAMPP
- A web browser
- A code editor such as Visual Studio Code

### Steps to Run the Project

1. Install XAMPP on your computer.
2. Copy the project folder into the XAMPP `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin in your browser.
5. Create a database using the name configured in the project.
6. Import the provided `database.sql` file into the database.
7. Configure the database connection in the project's database configuration file.
8. Open the application in your browser using your local server URL.
